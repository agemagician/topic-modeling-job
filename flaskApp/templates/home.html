Merck Employee Analytic Framework

Here you can find some information about how this platform works. The framework includes 3 tabs

Home

This tab provides information about navigating through the framework.

Employee Analytic

In order to use this tab, the results should be precomputed through Precompute Data tab.

This tab allows to select a visualization, Model, and other parameters such as Number of Clusters and N-gram. Below is a small description:

1) Employee Cluster: This is your assumption. If you had objective of employees from 4 departments, you would assume that the employee cluster is 4. You can also try different options to see which gives the best results.

2) N-grams: When picking topic words for each cluster, this parameter lets you decide the n-gram for the words N-gram = 1 would give you words such as "Talent" , "acquisition" whereas N-gram = 2 would give you words like "Talent-Acquisition"

3) Model: Offers different choice of models to use for clustering the employees

4) Visualizations: Various types of visualizations are available. More information related to each visualization is availble when results are displayed.

NOTE: you would only be able to see the options that have been precompute before hand.

Precompute Data:

Since running the algorithm can take some time, there is a separate tab which allows you to train all models and precompute the results beforehand for faster loading when doing analytics.

In this tab, you can upload a file (csv or excel) with new data. The data file must contains the following columns 'User ID (anonymus)', 'Objective_Name', 'Objective_Metric' .

You can also set the configurations for precompute.
